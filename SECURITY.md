## Reporting a Vulnerability

Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.
Do not open a public issue.
Instead, report the vulnerability privately by emailing vahe.martirosyan6@tumo.org.

In your report, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Any proof-of-concept code or screenshots (if available)
-The version of the project where the issue occurs

What to Expect

You should receive an initial response within 48–72 hours confirming that we received your report.
We will investigate the issue and may contact you for additional details.
If the vulnerability is confirmed, we will work on a fix and may coordinate with you before public disclosure.
If the report is declined (for example, if it is not a security issue), we will explain the reason.
We appreciate responsible disclosure and thank you for helping improve the security of this project.
